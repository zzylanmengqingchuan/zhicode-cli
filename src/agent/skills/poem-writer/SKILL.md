# 七言绝句创作指南

## 概述

七言绝句（简称"七绝"）是中国古典诗歌最精炼的形式之一。全诗四句，每句七字，
共二十八字，却要求意境完整、音韵和谐、结构精巧。

## 核心格律要求

### 1. 字数与句式
- **四句成诗**，每句**严格七字**，不得增减
- 总字数：**28字**
- 输出格式应为四行，每行一句

### 2. 押韵规则
- 偶数句（第2、4句）**必须押韵**
- 首句**可押可不押**
- 押平声韵，一韵到底，不得换韵
- 常用韵部（现代汉语拼音近似）：
  - 平水韵下平声：一先、二萧、四豪、七阳、八庚、十一尤、十二侵等
- 如果用户要求用特定字押韵，必须严格执行

### 3. 平仄格律（理想状态）

七言绝句常见格式（首句平起平收式示例）：

```
平平仄仄仄平平（韵）
仄仄平平仄仄平（韵）
仄仄平平平仄仄
平平仄仄仄平平（韵）
```

要点：
- 平仄交替，节奏点为二、四、六字
- 一三五不论，二四六分明（首句末字与韵脚必须严守）
- 避免出现孤平、三平调、三仄尾等拗口情况
- 若完美平仄与意境冲突，**意境优先**，但应保持大体协调

### 4. 对仗
- 绝句**不强制对仗**
- 但如能在两句间形成自然对仗，可增添诗意

## 结构章法：起承转合

| 位置 | 作用 | 要求 |
|------|------|------|
| 第一句（起） | 起句破题 | 点明时间、地点、景物或情感基调 |
| 第二句（承） | 承接展开 | 顺着首句之意，进一步描绘或递进 |
| 第三句（转） | 转折推进 | 引入新视角、新情境，制造波澜 |
| 第四句（合） | 收束点睛 | 揭示主旨、升华意境，余韵悠长 |

## 创作原则

### 1. 意在言外
- 绝句贵含蓄，不说尽
- 通过意象暗示情感，让读者回味
- 避免直白说教、口号式表达

### 2. 意象选取
- 善用传统诗歌意象：月、风、雨、山、水、花、柳、雁、舟、笛等
- 意象应服务于整体意境，避免堆砌

### 3. 语言风格
- 用词典雅凝练，一字千金
- 避免现代白话词汇、外来语、生造词
- 可适当化用经典诗句意境，但须出新意

### 4. 情感真挚
- 无论咏物、写景、抒情、言志，贵在真情实感
- 忌空洞无物、为赋新词强说愁

## 输出格式

每首诗按以下格式输出：

```
【题目】

第一句
第二句
第三句
第四句

【注释与赏析】（可选，用户要求时提供）
```

## 创作流程

1. **理解意图**：明确用户要求的主题、情感基调、特定意象或押韵要求
2. **构思意境**：确定全诗要营造的氛围（如苍凉、清丽、雄壮、婉约）
3. **确定韵脚**：选择符合意境的韵部
4. **起句破题**：写出第一句，定下全诗基调
5. **承转推进**：顺着起句展开，第三句制造转折
6. **收束点睛**：末句升华，余韵无穷
7. **校验格律**：检查字数、押韵，尽量兼顾平仄
8. **自我品评**：朗读一遍，感受节奏与意境是否和谐

## 示例

**主题：春日山行**

```
【山行遇春】

石径斜穿翠霭间，
桃花一树映清泉。
牧童遥指云深处，
便是人间二月天。
```

*韵脚：间、泉、天（先韵）*
*起句写山路春景，承句特写桃花清泉，转句引入牧童与远方，合句点出时令与人间春意。*

## 注意事项

- 绝不允许输出非四句或每句非七字的"绝句"
- 若用户要求其他诗体（如五言绝句、律诗、词），应说明此技能专精七绝，
  但可以尝试创作或建议其他诗体
- 如用户给出主题过于现代，可化用古典意象来表达，保持诗味
- 每首诗后标注韵脚，方便用户品鉴
